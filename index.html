Iniciando a construção do algoritmo de criptografia

Vamos começar a construir nosso algoritmo de criptografia, que inicialmente utilizava apenas números. No entanto, sabemos que senhas compostas apenas por números são consideradas fracas. Portanto, precisamos expandir nosso algoritmo para incluir letras.

Primeiro, vamos definir nosso alfabeto. Para isso, criaremos uma variável chamada alfabeto que conterá todas as letras do alfabeto em minúsculas:

Python 
alfabeto = "abcdefghijklmnopqrstuvwxyz"

Definindo a senha de exemplo

Agora, vamos pensar em uma senha composta por letras. Usaremos "marcelo" como exemplo. Precisamos definir essa senha em nosso código:

Python 
alfabeto = "abcdefghijklmnopqrstuvwxyz"
senha = "marcelo"

Convertendo letras em valores ASCII

O próximo passo é criar um laço de repetição que percorra cada letra do alfabeto. Para cada letra, utilizaremos a tabela ASCII para convertê-la em um número. Isso é feito com a função ord, que retorna o valor ASCII de um caractere:

Python 
alfabeto = "abcdefghijklmnopqrstuvwxyz"

for letra in alfabeto:
    numero = ord(letra)
    print(letra, numero)

Com esse código, conseguimos converter cada letra do alfabeto em seu respectivo valor ASCII. Isso nos permite manipular as letras de forma numérica, o que é essencial para a criptografia.
